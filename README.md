# Bookstart Calculator  
# 북스타트 개월 수 계산기

도서관 북스타트 프로그램에서 생년월일을 입력하면 아기 개월 수를 자동으로 계산하고, 출생 연월일에 따른 수령 단계를 판정해 주는 Windows용 프로그램입니다.

## 다운로드
👉 https://github.com/Tomepetty/bookstart-calculator/releases/latest

GitHub에 익숙하지 않다면 위 링크를 누른 뒤, 화면 아래쪽의 **Assets** 항목에서  `.exe`파일을 다운로드하세요.

## 배포 파일 안내

- `bookstart-calculator-common-v1.1.0.exe`: 일반 북스타트 단계 계산용
- `bookstart-calculator-hwaseong-v1.1.0.exe`: 화성시 50+ 책 꾸러미 안내 포함 버전

## 주요 기능

- 생년월일 6자리 또는 8자리 입력 지원
- 하이픈, 점, 슬래시가 포함된 날짜 입력 지원
- 실제 존재하지 않는 날짜 입력 방지
- 개월 수 자동 계산
- 북스타트 1단계, 2단계, 3단계 자동 판정
- 실행 중인 상태에서 다시 실행하면 기존 창을 앞으로 가져오기

## 입력 예시

- `241023`
- `20241023`
- `24-10-23`
- `2024.10.23`
- `2024/10/23`

## 수령 단계 기준

- 0개월 ~ 18개월: 1단계
- 19개월 ~ 35개월: 2단계
- 36개월 이상: 3단계
- 초등학생 이상은 수령 대상에서 제외 안내

## 지역별 기능

화성시 버전은 50+ 책 꾸러미 안내 기능을 포함합니다.

다른 지역에서 사용할 경우 공통 버전을 사용하세요.
